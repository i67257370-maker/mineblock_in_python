# Майнкрафт с ЖЫГУЛём на Python

Воксельная песочница в духе Minecraft на чистом Python: pygame + OpenGL.
Текстуры блоков генерируются процедурно (никаких внешних файлов не нужно),
мир создаётся случайно при каждом запуске. А ещё здесь есть **ЖЫГУЛЬ**
(ВАЗ-2101, вишнёвый) — в него можно сесть и погонять по холмам.

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Управление

| Клавиша | Действие |
|---|---|
| WASD | Ходьба / руль в ЖЫГУЛЕ |
| Мышь | Обзор |
| Пробел | Прыжок / тормоз-ручник в ЖЫГУЛЕ |
| Shift | Бег |
| Ctrl | Вниз (в режиме полёта) |
| F | Вкл/выкл режим полёта |
| ЛКМ | Сломать блок |
| ПКМ | Поставить блок |
| 1–7 | Выбор блока в хотбаре |
| E | Сесть в ЖЫГУЛЬ / выйти |
| Esc | Освободить курсор |

## Как покататься

Подойди к ЖЫГУЛю ближе 3 блоков и нажми **E**. W — газ (до ~85 км/ч по спидометру
в заголовке окна), S — задний ход и тормоз, Пробел — ручник, A/D — поворот.
Повторное **E** — выйти из машины.

## Файлы

- `main.py` — игровой цикл, рендер, HUD, обработка ввода
- `world.py` — генерация рельефа (шум), деревья, чанк-лист, raycast
- `player.py` — физика игрока, AABB-коллизии
- `renderer.py` — вывод в OpenGL (мир, текстуры, модель ЖЫГУЛЯ)
- `car.py` — ЖЫГУЛЬ: модель из блоков, вождение, коллизии
- `tex.py` — процедурные текстуры (атлас 16×16 тайлов)
