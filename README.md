# Жигули: Бесконечная дорога 3D

Трёхмерная игра на **Three.js (WebGL)** — без Python, без установки,
без внешних ассетов. Все текстуры (асфальт с трещинами и разметкой,
трава, кирпич, черепица, канистра) генерируются процедурно, свет —
солнце с мягкими тенями, туман и cinematic-тонемаппинг.

Сначала пешком собираем Жигуль по деталям: 4 колеса, двигатель, АКБ.
Потом находим канистру, заправляемся и заводимся.
А дальше — бесконечная дорога с АЗС, домами у обочины и канистрами
на асфальте. Бензин тает на глазах — как далеко уедешь?

## Запуск

Просто открой `index.html` двойным кликом в браузере (Chrome / Edge / Firefox).
Библиотека three.js лежит рядом (`vendor/three.min.js`), так что
интернет и сервер не нужны.

Если браузер ограничил локальный файл — запусти любой статический сервер:

```bash
python3 -m http.server 8000   # или: npx serve
# потом открой http://localhost:8000
```

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | Ходьба (пешком) / газ, тормоз, руль (в машине) |
| E | У машины: заправить из канистры и завестись |
| Enter / Space | Старт / рестарт после проигрыша |

## Как играть

1. **Сборка.** Подойди к каждой детали на стартовой поляне — колесо
   встанет на ступицу, двигатель — под капот, АКБ — на место.
2. **Канистра.** Зелёная канистра лежит западнее поляны — подбери её.
3. **Заводим.** Подойди к машине, нажми **E** — кузов станет вишнёвым,
   фары загорятся, в баке будет 42 литра.
4. **В путь.** **W** — газ (до ~90 км/ч), **S** — тормоз, **A/D** — руль.

По дороге встречаются:

- **АЗС** — заезжай на площадку и останавливайся: бак заполняется сам
  (рамка топлива мигает зелёным);
- **канистры** — на асфальте и у домов, дают +25 л;
- **ямы** — резко гасят скорость;
- **дома, деревья** — у обочины, для антуража.

Выезд на траву медленный и прожорливый. Когда бак опустеет и машина
встанет — увидишь километраж и рекорд. Enter — попробовать снова.
