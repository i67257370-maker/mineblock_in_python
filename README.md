# Жигули: Бесконечная дорога

Маленькая 2D-игра на чистом Python + pygame, всё в одном файле `road.py`,
без внешних ассетов.

Сначала пешком собираем Жигуль по деталям: колёса x4, двигатель, АКБ.
Потом находим канистру с бензином, заправляемся и заводимся.
А дальше — бесконечная дорога: АЗС, дома у обочины и канистры прямо
на асфальте. Бензин тает на глазах — как далеко уедешь?

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python road.py
```

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | Ходьба (пешком) / газ, тормоз, руль (в машине) |
| E | Действие у машины: заправить и завестись |
| Enter / Space | Старт игры / рестарт после проигрыша |
| Закрыть окно | Выход |

## Как играть

1. **Сборка.** Подойди к каждой детали на стартовой поляне — она сама
   прилипнет к Жигулю (счётчик `N/6` под машиной).
2. **Канистра.** Зелёная канистра лежит левее — подбери её.
3. **Заводим.** Подойди к машине и нажми **E** — бак получит 42 л.
4. **В путь.** **W** — газ, **S** — тормоз, **A/D** — руль.

Топливо тратится быстрее на скорости и на траве. На карте появляются:

- **АЗС** — подъезжай к колонке, бак заполняется сам;
- **канистры** на дороге — +25 л, у домов канистры тоже бывают;
- **ямы** — сбрасывают скорость.

Когда бензин кончится и машина встанет — увидишь пройденный километраж
и рекорд. Enter — попробовать снова.
